# Song-Spark-CPSC-1001-Final-Project
Project title: Song Spark 
Group Members: Corinne Laurey

This program gives the user a semi-randomized playlist based off of Corinne's music taste. The user starts the program and 
clicks on buttons to make their custom playlist. They can choose 5-15 songs for their playlist and choose which genres of 
music they would like to include. Preview buttons offer one song option for each category to help the user decide what 
they would like to create. This requires a mouse/trackpad and a computer speaker or headphones. 

There are 7 required java files to run this program.
- WelcomeGUI.java
- QuestionOneGUI.java
- QuestionTwoGUI.java
- QuestionThreeGUI.java
- PlaylistHelper.java
- Song.java
- StdAudio.java (not modified)

There are 5 required text files that contain song information for each genre. These are:
- Classical.txt 
- Pop.txt 
- KPop.txt 
- MusicalTheater.txt 
- Random.txt 

There are 5 required wav files that contain song previews:
- ClassicalClip.wav
- KPopClip.wav 
- MTClip.wav
- PopClip.wav
- RandomClip.wav 

There are 3 required images within the program:
-SongSparkWelcomeDesign.png 
-SongSparkQ1Design.png 
-SongSparkQ2Design.png 

If a user would like to modify this program to their own music taste, they could add songs in the txt files in the following 
format (one song per line):
Song Title;Song Artist|mm.ss/yyyy-mm-dd

WelcomeGUI.java contains the primary main method, so the program should be run like:
java WelcomeGUI 

There are no AI generated components. All visuals are drawn.

Oracle was used as a reference for topics not discussed in class, such as LocalDate and GridLayout features.
